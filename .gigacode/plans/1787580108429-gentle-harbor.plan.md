# План документирования кода согласно spec.md

## Контекст

Проект **data-collector** — часть системы сбора и аналитики чрезвычайных сообщений о ракетных ударах и атаках БПЛА Белгородской области (спецификация `belea/specs`).

Необходимо добавить JavaDoc документацию ко всем публичным классам в соответствии со спецификацией раздела [11](#11-архитектура-системы) и моделями данных (разделы 9-10).

## Формат JavaDoc

```java
/**
 * Описание класса с ссылкой на раздел спецификации.
 *
 * @see <a href="https://gitverse.ru/belea/specs/content/master/docs/spec.md">Спецификация системы</a>
 */
public class ClassName {
    /**
     * Описание поля.
     *
     * @see <a href="https://gitverse.ru/belea/specs/content/master/docs/spec.md#раздел">Раздел спецификации</a>
     */
    private Type field;
}
```

Для enum:
```java
public enum EnumName {
    /**
     * Описание значения.
     */
    VALUE
}
```
